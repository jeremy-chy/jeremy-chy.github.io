Why I started writing things down

Jun 18, 2026

This is an example article. It exists so the layout and links work end-to-end. Replace this file (or copy it) to publish your own thoughts.

How to add a new post

Duplicate this file inside the thinking/ folder, give it a descriptive name like 2026-06-18-my-idea.html, then edit the title, date, and body below. Finally, add an entry pointing to it at the top of the thinkingPosts array in thinking-data.js.

Write freely

You can use normal HTML here: paragraphs, links, headings, lists, images, and so on. Keep it simple and the shared stylesheet will handle the typography.
